# Material Explorer icons

These selected SVG assets come from the
[Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)
project and are redistributed under its MIT license; see `LICENSE` in this
directory.

PyEMSI maps them to common file types and named folders. Branded file icons are
documented separately in `../BRAND_ASSETS.md`; neutral mesh files use the
simulation-diagram icon from this set.
