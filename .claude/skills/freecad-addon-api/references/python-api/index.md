## Scope and limits

This source-only catalogue supplements the [binding catalogue](../api/index.md). [Selection and usage guide](../python-api-guide.md). It does not import FreeCAD, run decorators, resolve dynamic/conditional `__all__`, expand wildcard imports, or verify installed paths. Signatures, docstrings, guards, aliases and lifecycle decorators are copied from source. Facade reexports, literal export lists, other source-defined names and private internals are distinguished. Imported dependencies and public-looking source names are not automatically supported API.

Selection: Draft facades/factories/operations/geometry plus their direct reexport source modules; all `src/Ext/freecad` modules including the namespace initializer template; Arch facade and direct star-import sources; selected Part shape, FEM creation/geometry/mesh/result, TechDraw, Sketcher profile and CAM Path helpers. Unrelated GUI/test internals and arbitrary transitive dependencies are omitted. Included GUI command modules/reexports still require appropriate GUI availability. Nested classes, function-local definitions, dynamically attached APIs and dynamic runtime property contracts are not inventoried. Unannotated arguments/returns remain unspecified.
