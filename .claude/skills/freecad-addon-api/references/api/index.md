## Reading limits

- Public module names here are stub-emitted/source-discovered, not verified imports in an installed FreeCAD. Optional builds can differ.
- Signatures, decorators, documentation, inheritance and aliases are copied from stubs. Source-to-symbol implementation mappings are not inferred. Evidence locations refer to the stub input tree.
- `Any`, undocumented entries, typing-only helpers and unspecified defaults require implementation/runtime checks. No exception, unit, side-effect or writable-property contract is inferred when absent.
- Dynamic document properties omitted by the existing generator and pure Python workbench packages require source inspection. See [modeling guidance](../modeling-api.md).
- Generated docs preserve upstream descriptions, including limitations and legacy syntax. Examples and runtime behavior have not been exercised by this renderer.
